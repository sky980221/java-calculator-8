# java-calculator-precourse: 문자열 덧셈 계산기
입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현합니다. 

## 기능 구현
1. 입출력 기능 구현 
2. 빈 문자열(`""`) 또는 `null`을 입력할 경우 0 반환 기능
3. 기본 구분자(, :) 분리 기능
4. 커스텀 구분자("//"와 "\n" 사이에 위치하는 문자) 처리 기능
5. 숫자 합산 기능
6. 잘못된 문자열 입력시 IllegalArgumentException 발생 기능

## 개발 방식
TDD(테스트 주도 개발)를 시도합니다.
1. 실패하는 테스트를 만들고
2. 통과시키는 코드를 작성합니다
3. 코드를 정리합니다. 

이 과정을 반복합니다.
